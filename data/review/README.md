# Review decisions

One file per reviewed year of backfill candidates, `decisions-<year>.json`, in the format described
in [docs/REVIEW.md](../../docs/REVIEW.md). Rejections and their reasons are kept here as the record
of what was examined.

`council-time/` holds the reviewed classification and inputs for the council-time dataset: the
thread of each transcript segment and correspondence heading, the clock of each court-reporter
transcript, speaker turns on a thread during public comment, and links between threads. See
[docs/COUNCIL_TIME.md](../../docs/COUNCIL_TIME.md).
